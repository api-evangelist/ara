Ara (Ara Labs, Inc.) is a digital out-of-home (DOOH) advertising network that finances,
installs, and operates rich-media displays across mobility, municipal, parking, and retail
settings. Through a long-term partnership with Uber it describes itself as the largest U.S.
owner-operator of rideshare and taxi-top digital billboards, alongside in-car, storefront,
and parking/municipal kiosk screens. Ara owns the hardware and the content-management
operation and charges partners a monthly subscription so they avoid cap-ex.

## API surface

**Ara publishes no public API.** There is no developer portal, no documentation site, no
OpenAPI/AsyncAPI/GraphQL/Postman artifact, no SDK, and no webhook catalog anywhere on any
Ara host. Contract discovery was run against every host resolved from the domain.

- `https://api.arascreens.com` — a live Ruby on Rails application on Heroku. Every route is
  behind HTTP Basic authentication (`401`, `WWW-Authenticate: Basic realm="Application"`);
  unmatched routes return the default Rails 404 page. This is the private backend of Ara's
  own applications, not a developer-facing API. No spec is served at `/openapi.json`,
  `/openapi.yaml`, `/swagger.json`, `/v1/openapi.json`, `/api-docs`, `/docs`, `/redoc` or
  `/graphql` — all 404.
- `https://app.arascreens.com` — Ara's React single-page driver and operations application
  (cartop enrollment, earnings, vehicles, medallions, warehouses, purchase orders). Its
  catch-all route answers `200` with the same HTML shell for every path, so no `200` from
  this host is evidence of a served document.
- `https://cms.arascreens.com` — front end for a third-party digital-signage CMS
  ("WiCanvas"), served from CloudFront/S3; every other path returns `403`.
- `https://www.arascreens.com` — Squarespace marketing site. Eleven pages in the sitemap,
  none developer-facing.

## Pricing

- 1 Hour — $500.00
- 2 Hours — $800.00
- Full Day — $2,000.00
- Larger or custom campaigns — by email, no published price.

Partner/operator side (fleet owners, retailers, parking operators, municipalities) is a
monthly subscription with no published price; contact-only.
