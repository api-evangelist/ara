Ara (Ara Labs, Inc.) is a digital out-of-home (DOOH) advertising network that finances,
installs, and operates rich-media displays across mobility, municipal, parking, and retail
settings. Through a long-term partnership with Uber it describes itself as the largest U.S.
owner-operator of rideshare and taxi-top digital billboards, alongside in-car, storefront,
and parking/municipal kiosk screens. Ara owns the hardware and the content-management
operation and charges partners a monthly subscription so they avoid cap-ex.

## API surface

**Ara publishes no public API.** There is no developer portal, no documentation site, no
OpenAPI/AsyncAPI/GraphQL/Postman artifact, no SDK, and no webhook catalog anywhere on any
Ara host. Contract discovery was run against every host resolved from the domain.

- `https://api.arascreens.com` — a live Ruby on Rails application on Heroku. Every route is
  behind HTTP Basic authentication (`401`, `WWW-Authenticate: Basic realm="Application"`);
  unmatched routes return the default Rails 404 page. This is the private backend of Ara's
  own applications, not a developer-facing API. No spec is served at `/openapi.json`,
  `/openapi.yaml`, `/swagger.json`, `/v1/openapi.json`, `/api-docs`, `/docs`, `/redoc` or
  `/graphql` — all 404.
- `https://app.arascreens.com` — Ara's React single-page driver and operations application
  (cartop enrollment, earnings, vehicles, medallions, warehouses, purchase orders). Its
  catch-all route answers `200` with the same HTML shell for every path, so no `200` from
  this host is evidence of a served document.
- `https://cms.arascreens.com` — front end for a third-party digital-signage CMS
  ("WiCanvas"), served from CloudFront/S3; every other path returns `403`.
- `https://www.arascreens.com` — Squarespace marketing site. Eleven pages in the sitemap,
  none developer-facing.
- `https://outdoor.arascreens.com` — product marketing page for the Ara O49 55" display,
  built as a Vite/React SPA. It returns a real `404` for paths with a file extension but
  the same 11,626-byte HTML shell for every extensionless path, so `/docs`, `/api-docs`
  and `/graphql` all "exist" here and none of them is real — a nonsense control path
  returns a byte-identical page.
- `https://rts.arascreens.com` — an unauthenticated Node/Express service whose root returns
  the 23-byte scaffold string `respond with a resource`. Every other path, including
  `/health` and `/openapi.json`, returns a 9-byte `404`. No routes and no contract.
- `https://stationary.arascreens.com` — `404` with an empty body on every path.
- `https://assets.arascreens.com` — CloudFront/S3 asset origin; `403 AccessDenied` on
  every path.

## About Ara's "API-driven" claim

Ara's own outdoor-display marketing page says its CMS is **"API-driven"** — *"Ara's
API-driven CMS controls screens and monitors fleet health — or plug in the platform you
already run"*, listed as a product feature alongside "Cloud-hosted" and "SOC media
playback". Read this correctly: it is a statement that Ara's **internal** content-management
platform is programmatically operated, and an offer to integrate with a partner's existing
signage stack. **It is not an offer of a public API to third parties.** There is no
developer portal, no documentation, no key issuance, no published contract, and no
mechanism to request access. An agent must not treat the phrase "API-driven" on the
marketing site as evidence that a callable Ara API exists.

## What an agent should know

- There is nothing here to call. Do not synthesize an Ara API client, base URL, or endpoint
  list — no contract exists, and `api.arascreens.com` is credentialed private infrastructure.
- Ara ships no SDK or client library in any public package registry. npm, PyPI, RubyGems,
  crates.io, Packagist and NuGet were all queried and all returned nothing first-party.
- Ara has no GitHub organization. `github.com/ara-labs` is an unrelated AI-research
  organization and `github.com/aralabs` is empty; neither belongs to Ara Labs, Inc.
- Buying Ara advertising is a human/commerce flow on the Squarespace storefront or an email
  to support@arascreens.com.
- Becoming a cartop driver is a human enrollment flow at https://app.arascreens.com/sign_up.
